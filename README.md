# libds

A small C data structures library, built from scratch as a systems-programming exercise. Everything is written with `void*`-based generics, manual memory management, and no external dependencies — just libc.

## What's implemented

| Structure | Header | Type |
|---|---|---|
| Dynamic array | `include/dynamic_array.h` | `da` |
| Doubly linked list | `include/linked_list.h` | `dll` |
| Stack | `include/stack.h` | `stack` |
| Queue | `include/queue.h` | `qu` |
| Hash map (djb2, separate chaining) | `include/map.h` | `map` |

All containers are generic over element type via `size_t element_size` passed at init time, with values copied by `memcpy` into internally owned memory.

## Build

```bash
make        # builds build/libds.a
make clean  # removes build/
```

The Makefile auto-discovers every `.c` file in `src/` and compiles it into `build/<name>.o`, then archives all object files into `build/libds.a` using `ar rcs`.

## Usage

Run this in the project root .
Link against the static library and include the headers you need:

```bash
gcc -Iinclude your_program.c -Lbuild -lds -o your_program
```

### Dynamic array

```c
#include "dynamic_array.h"

da *arr = da_init(sizeof(int));

int x = 42;
da_append(arr, &x);

int y = *(int *)da_get(arr, 0);
da_set(arr, 0, &y);

da_free(arr);
```

### Doubly linked list

```c
#include "linked_list.h"

dll *list = dll_init(sizeof(int));

int x = 10;
dll_append(list, &x);
dll_insert(list, 0, &x);

int y = *(int *)dll_get(list, 0);
dll_set(list, 0, &y);

dll_free(list);
```

### Stack

```c
#include "stack.h"

stack *s = stack_init(sizeof(int));

int x = 5;
stack_push(s, &x);

const void *top = stack_peek(s);
stack_pop(s);

stack_free(s);
```

### Queue

```c
#include "queue.h"

qu *q = queue_init(sizeof(int));

int x = 1;
enqueue(q, &x);

int out;
dequeue(q, &out);

if (is_empty(q)) { /* ... */ }

queue_free(q);
```

### Map

```c
#include "map.h"

map *m = map_init();

int x = 7;
map_add(m, "key", &x, sizeof(int));

int *found = (int *)map_get(m, "key");

map_free(m);
```

## Project layout

```
include/    public headers for each container
src/        implementation, one .c file per container
examples/   standalone demo programs 
build/      generated .o files and libds.a (gitignored / regenerated by make)
Makefile    build rules
```

## Requirements

- GCC (or any C11-compliant compiler)
- GNU Make
